Create a complete modern web-based **Bazar, Member Account, Expense & Bill Management System** using **Laravel + MySQL + Bootstrap 5 / AdminLTE**.

The software will replace an existing Excel-based accounting system. All calculations should be automated, and members should be able to log in and see their own balances, payments, bills, expenses, and reports.

## User Roles

### Admin
Admin should have full control of the system.

Admin can:
- Create, edit, deactivate, and delete members
- Manage member opening balances
- Add deposits/payments received from members
- Add daily/monthly expenses
- Create and manage bills
- Manage expense categories
- Make adjustments
- View all transactions
- Generate reports
- Print/download reports
- Manage users and permissions
- View dashboard summaries

### Member
Each member will have their own login.

After login, a member can only see their own financial information.

Member dashboard should show:
- Current Balance
- Total Deposit/Paid
- Total Bill
- Total Expense Share
- Previous Due
- Current Due
- Advance Balance
- Recent Transactions
- Monthly Summary

Members cannot modify accounting data.

## Member Management

Store:
- Member ID
- Name
- Phone
- Email
- Address
- Join Date
- Opening Balance
- Status
- Login Password

Member ID should be generated automatically.

## Member Deposits / Collections

Admin can record money received from members.

Fields:
- Member
- Date
- Amount
- Payment Method
- Reference/Transaction ID
- Note
- Received By

Payment methods:
- Cash
- Bank
- bKash
- Nagad
- Rocket
- Other

Every payment must automatically update the member ledger and balance.

## Expense Management

Admin can add all expenses.

Fields:
- Date
- Expense Category
- Description
- Amount
- Paid By
- Payment Method
- Voucher/Reference Number
- Attachment
- Note

Expense categories can include:
- Bazar
- Electricity
- Gas
- Water
- Internet
- Rent
- Maintenance
- Cook
- Cleaning
- Transport
- Other

Admin must be able to create new expense categories.

## Bazar Management

Create a dedicated Bazar module.

Fields:
- Date
- Bazar By
- Shop/Market
- Item
- Quantity
- Unit Price
- Total Price
- Note

Allow multiple items under one Bazar entry.

Automatically calculate:

Item Total = Quantity × Unit Price

Bazar Total = Sum of all item totals

Show daily and monthly Bazar reports.

## Bill Management

Admin can create monthly bills for members.

Example:
- Month
- Member
- Previous Due
- Monthly Charge
- Expense Share
- Other Charge
- Discount/Adjustment
- Total Bill
- Paid Amount
- Due Amount

Calculation:

Total Bill = Previous Due + Monthly Charge + Expense Share + Other Charge - Discount

Due Amount = Total Bill - Paid Amount

If payment is higher than the bill, show the remaining amount as Advance Balance.

## Expense Sharing

Provide an option to distribute expenses among members.

Admin can choose:
- Equal distribution
- Selected members only
- Custom amount
- Custom percentage

Example:

Total Expense = 30,000 BDT
Active Members = 10

Expense Per Member = 30,000 / 10 = 3,000 BDT

The distributed amount should automatically appear in each member's ledger.

## Member Ledger

Maintain a complete ledger for every member.

Columns:
- Date
- Description
- Reference
- Debit
- Credit
- Running Balance

Every financial operation should automatically create the appropriate ledger entry.

Do not manually store calculated balances where unnecessary. Maintain a proper transaction/ledger structure and calculate balances reliably from transactions.

## Monthly Closing

Create a monthly closing system.

At the end of each month:
- Calculate total collection
- Calculate total expenses
- Calculate each member's bill
- Calculate paid amount
- Calculate due/advance
- Carry outstanding balance to next month

Once a month is closed, normal users should not be able to modify its transactions.

Admin can reopen a closed month with proper authorization and an audit log.

## Audit Log

Keep a record of important actions:

- Created by
- Updated by
- Deleted by
- Date/time
- Old value
- New value
- IP address where appropriate

Financial records should preferably use soft deletes instead of permanent deletion.

## Excel Migration

The existing Excel file contains the current accounting records.

Create an Excel Import module that can migrate:
- Members
- Opening balances
- Previous dues
- Deposits
- Expenses
- Bills
- Existing balances

Before importing:
1. Preview the Excel data.
2. Validate every row.
3. Show invalid/duplicate rows.
4. Allow the admin to confirm the import.
5. Prevent duplicate transactions.
6. Keep an import history.

The new software's calculations should reproduce the accounting logic of the existing Excel workbook, while using a proper database/ledger-based accounting structure.
